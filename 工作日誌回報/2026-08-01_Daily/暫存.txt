5、處理 Ubuntu 的時間問題

   1、在 Ubuntu 的 Terminal 中輸入 sudo timedatectl set-ntp true 、 sudo systemctl restart systemd-timesyncd 、timedatectl
      
   2、得到結果是目前時間
           Local time: Sat 2026-08-01 02:52:21 CST
           Universal time: Fri 2026-07-31 18:52:21 UTC
           RTC time: Sat 2026-08-01 02:52:14
           Time zone: Asia/Taipei (CST, +0800)

  3、手動修時間，輸入 sudo date -s "2026-08-01 HH:MM:SS"

  4、重新登入 Ubuntu。螢幕中間上方會有目前時間

8、Track A 的軟體安裝

   1、iperf3 彈窗，問是否要在背景執行，選 no。如圖片10

   2、pip3 install pandas matplotlib seaborn --break-system-packages，Ubuntu 26 版本的關係，要額外安裝這個

   3、消除 path warning 的問題，輸入 echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc、source ~/.bashrc

   4、安裝 Docker sudo apt install -y docker.io 、 sudo usermod -aG docker $USER

   5、確認 docker 版本，docker --version，得到 Docker version 29.1.3, build 29.1.3-0ubuntu4.1

   6、重新啟動並進入 Ubuntu
