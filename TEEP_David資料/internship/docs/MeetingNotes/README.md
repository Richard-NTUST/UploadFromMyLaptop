# Meeting Notes

This folder stores discussion notes using the Open Research Playbook `F-meeting-notes` format.

Use this folder for discussions with mentors, senior students, collaborators, or lab staff. Each discussion should have:

* agenda or discussion topics;
* consensus or decision;
* concrete action items;
* owner;
* due date;
* evidence location.

Naming convention:

```text
YYYY-MM-DD_Topic.md
```
